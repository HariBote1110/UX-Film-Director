TS: 2つの fade の opacity を掛け合わせるため、  
`1 * 0.5 * 0.5 = 0.25`

Rust: `fade = clamp(...)` で毎回上書きするため、最後に処理された fade の値だけが残り、  
`0.5`（どちらも 0.5 なら最後の fade の 0.5）

差異が生じる条件:  
有効な fade フィルタが複数ある場合。  
TS は全 fade の opacity を乗算して合成する。  
Rust は最後に走査した fade の opacity で上書きし、それ以前の fade を無視する。

片方だけに現れる振る舞い:  
TS には「複数 fade の累積・乗算」があり、順序に依存せず全部の効果が掛かる。  
Rust には「最後の fade のみ有効」という上書き挙動があり、走査順に依存する。
