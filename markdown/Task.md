# タスク定義

## 追加タスク（2026-02-11）
- AviUtl 互換性を拡張するため、現行実装とのギャップ分析を実施する。
- 比較対象は `AviUtl version 1.10 (aviutl110)` と `拡張編集 0.92 (exedit92)` とする。
- ギャップを `markdown/` に明文化し、実装優先順位（P0〜P3）を定義する。
- 直近は「機能カバレッジを最大化する基盤項目」を優先対象とする。
- P0-1 として、プロジェクト保存/読込（UI・IPC・復元処理）を実装する。
- P0-2 として、レイヤー運用拡張（100レイヤー、表示/ロック、名称変更、保存復元）を実装する。
- P0-3 として、複数選択・コピー貼り付け・複製・グループ化/解除を実装する。
- P0-4 として、フィルタスタック基盤（追加/削除/順序変更/ON-OFF）を実装する。
- P0-5 として、音声統合エクスポート（タイムライン音声の合成出力連携）を実装する。
- P1-1 として、中間点 UI と補間管理（キーフレーム編集）を実装する。
- P0-3 追加として、複数選択オブジェクトの切り取り（Cut）を実装する。
- P0-3 追加として、タイムライン上の範囲選択（矩形選択）を実装する。
- P0-3 追加として、複数選択オブジェクトへの一括変形を実装する。

## 背景
- 本アプリは React + Zustand + PixiJS + Electron 構成で、再生中・ドラッグ中・書き出し時に負荷が上がりやすい。
- 既存コードでは、状態更新のたびに広範囲な再レンダリングが発生しやすい。
- 画像書き出しで `base64` 変換を使っており、CPU とメモリのオーバーヘッドが大きい。

## 目的
- 編集操作時の体感レスポンスを改善する。
- 再生中の UI 再描画コストを下げる。
- エクスポート時のフレーム転送を軽量化し、書き出し処理を安定化する。
- TypeScript の残存エラーを解消し、ビルド可能状態を回復する。
- Rust 別プロセス化に向けた第1段階として、Electron との IPC 疎通基盤を構築する。
- Rust 別プロセス化の第2段階として、書き出しパイプラインの制御を Rust 側へ移管する。
- Rust 別プロセス化の第3段階として、メディアメタデータ解析（`ffprobe`）を Rust 側へ移管する。
- PSD 読み込み後の同期処理の体感遅延を削減し、表情切り替えの反映速度を改善する。
- ローカルビルド時の macOS コード署名を無効化し、証明書依存でビルドが止まらない状態にする。
- PSDToolKit(webview) 依存を撤廃し、`ag-psd` ベースのローカル解析・描画・レイヤー制御へ再構築する。
- PSD レイヤー画像の `ImageData` 互換性問題を解消し、表示欠落しない状態へ修正する。
- Pixi の `Image element passed` 警告を抑制し、PSD レイヤーテクスチャの取込経路を安定化する。
- PSD レイヤーの描画前後関係（Z順）を PSD 側の順序と一致させる。
- 動画/音声オブジェクトの音量とミュートをプロパティパネルから編集できるようにする。
- PSD オブジェクトのスケーリングをプロパティパネルから編集できるようにする。
- 立ち絵（PSD）選択時の黄色枠が表示内容とずれないよう、選択枠の基準を実描画境界へ揃える。
- 長尺エクスポート時に `ffmpeg` の `stderr` パイプ詰まりで書き出しが停止しないようにする。
- ラジオグループ配下にサブグループがある PSD でも、選択時に祖先ラジオグループまで排他制御を適用し、常に1候補のみ有効にする。
- プロジェクトの保存/読込を可能にし、再起動後に編集状態を再開できるようにする。

- `markdown/Implementation_Plan.md`: 実装方針と優先順位。

- 署名無効化済みの `build` スクリプト設定。
- PSDToolKit を使わない PSD 解析/表示/表情トグルの実装。
- `ImageData` / `Uint8Array` / `Uint8ClampedArray` を正規化する PSD 画像変換処理。
- canvas 経由のテクスチャ生成による Pixi 警告抑制実装。
- PSD レイヤー順序を保持した描画順制御。
- `PropertyPanel` の動画/音声用 `Volume` / `Mute` UI と反映ロジック。
- `PropertyPanel` の PSD 用 `Scale` UI と反映ロジック。
- 選択枠を `content` の実境界に追従させる表示補正。
- `ffmpeg` `stderr` のドレイン詰まりを回避するエクスポート安定化修正。
- 祖先ラジオグループまで考慮した PSD レイヤー排他制御の修正。
- プロジェクトファイル（`*.uxfd.json`）の保存/読込機能と復元ロジック。
- レイヤー状態（名称/表示/ロック）の編集 UI とプロジェクト保存/読込対応。
- 複数選択、クリップボード操作、グループ化/解除の操作基盤。
- `cutSelectedObjects` と `Ctrl/Cmd + X` を含む切り取り操作導線（ツールバー/右クリックメニュー）。
- タイムライン空白ドラッグでの範囲選択（加算選択対応）と選択矩形表示。
- `PropertyPanel` から複数選択へ同時適用できる一括変形 UI（移動/拡大率/回転/不透明度）。
- フィルタスタック（色調補正/クリッピング/振動/影）の操作基盤と同期ロジック。
- エクスポート時の音声ミックス生成と `ffmpeg` 連携。
- キーフレーム（中間点）の追加/編集/削除と補間設定 UI。
