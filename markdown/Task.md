## 背景
- 本アプリは React + Zustand + PixiJS + Electron 構成で、再生中・ドラッグ中・書き出し時に負荷が上がりやすい。
- 既存コードでは、状態更新のたびに広範囲な再レンダリングが発生しやすい。
- 画像書き出しで `base64` 変換を使っており、CPU とメモリのオーバーヘッドが大きい。

## 目的
- 編集操作時の体感レスポンスを改善する。
- 再生中の UI 再描画コストを下げる。
- エクスポート時のフレーム転送を軽量化し、書き出し処理を安定化する。
- TypeScript の残存エラーを解消し、ビルド可能状態を回復する。
- Rust 別プロセス化に向けた第1段階として、Electron との IPC 疎通基盤を構築する。
- Rust 別プロセス化の第2段階として、書き出しパイプラインの制御を Rust 側へ移管する。
- Rust 別プロセス化の第3段階として、メディアメタデータ解析（`ffprobe`）を Rust 側へ移管する。
- PSD 読み込み後の同期処理の体感遅延を削減し、表情切り替えの反映速度を改善する。
- ローカルビルド時の macOS コード署名を無効化し、証明書依存でビルドが止まらない状態にする。
- PSDToolKit(webview) 依存を撤廃し、`ag-psd` ベースのローカル解析・描画・レイヤー制御へ再構築する。
- PSD レイヤー画像の `ImageData` 互換性問題を解消し、表示欠落しない状態へ修正する。
- Pixi の `Image element passed` 警告を抑制し、PSD レイヤーテクスチャの取込経路を安定化する。
- PSD レイヤーの描画前後関係（Z順）を PSD 側の順序と一致させる。
- 動画/音声オブジェクトの音量とミュートをプロパティパネルから編集できるようにする。
- PSD オブジェクトのスケーリングをプロパティパネルから編集できるようにする。
- 立ち絵（PSD）選択時の黄色枠が表示内容とずれないよう、選択枠の基準を実描画境界へ揃える。
- 長尺エクスポート時に `ffmpeg` の `stderr` パイプ詰まりで書き出しが停止しないようにする。
- ラジオグループ配下にサブグループがある PSD でも、選択時に祖先ラジオグループまで排他制御を適用し、常に1候補のみ有効にする。
- プロジェクトの保存/読込を可能にし、再起動後に編集状態を再開できるようにする。
- 音声のみを `mp3` 形式で書き出せるようにする。
